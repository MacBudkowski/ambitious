# Changelog

## 2.1.0 — 2026-10-16

Renamed to **ambitious**. Removed the evaluation harness and results from the published tree; they measured the earlier design and remain in the git history (tag `v1.0.0-suggest`).

## 2.0.0 — 2026-10-16

Redesigned as an **ambition pass** for the user: the goal behind the goal, then a ladder of 2–3 bolder, ready-to-send prompts with what each needs and how to check it, then the user picks. Asks a few questions first when that improves fit. When invoked it returns prompts only (no draft, no critique). Added `references/precedents.md` (20 sourced cases).

## 1.0.0 — 2026-10-16

Published as `stay-ambitious`. The agent added one short suggestion after answering. Per-type reference files with the essay's text for each type, host-neutral Agent Skills frontmatter, and structural tests. Tagged `v1.0.0-suggest`.

## 0.3.6 and earlier

Published as `ambition-check`.
